### Project Overview
Designed and prototyped an automated mechatronic exhaust system driven by a Raspberry Pi Pico W microcontroller. The system actively monitors ambient environmental parameters using integrated sensors, displaying real-time data—such as temperature and system status—on an OLED display.

## Key Engineering Contributions
- **Thermal & System Architecture**: Designed a automated temperature-controlled exhaust fan system integrating a Raspberry Pi Pico 2W microcontroller, an AHT10 environmental sensor, and an L298N motor driver to dynamically manage thermal thresholds.
- **Circuit Design & Prototyping**: Engineered custom circuit layouts and simulated connections in Multisim, handling power distribution, MOSFET/driver switching logic, and OLED display integration for real-time sensor telemetry.
- **Embedded Firmware & Integration**: Developed and deployed Python/MicroPython control scripts to process real-time environmental data from the AHT10 sensor and modulate fan speeds via PWM through the L298N driver based on active temperature feedback.
