### Project Overview
Designed and prototyped an automated mechatronic exhaust system driven by a Raspberry Pi Pico W microcontroller. The system actively monitors ambient environmental parameters using integrated sensors, displaying real-time data—such as temperature and system status—on an OLED display.

### Key Engineering Features
* **Automated Thermal Control:** Developed custom embedded control logic to dynamically adjust exhaust fan speeds based on real-time temperature threshold triggers.
* **Telemetry Display:** Integrated an OLED screen via I2C interface to display live system metrics, operational state, and temperature readings.
* **Hardware Integration:** Designed and wired a breadboard circuit using L298N drivers, status indicator LEDs, and power regulation for reliable actuation.
